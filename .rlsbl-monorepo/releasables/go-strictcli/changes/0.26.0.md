## 0.26.0

### Features

- [go-strictcli] **Connection env vars.** Declare a hermetic-suppressed connection URL (e.g. a database DSN) at app level with `WithConnectionEnv`; bind flags to it with `ConnectionURLFlag` (lazily read, no default, cli>env), and read it from checks via the `ConnectionEnvReader` capability. Under `--hermetic` it resolves absent so connection-dependent behavior skips visibly.
